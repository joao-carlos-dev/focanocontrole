# Family Money Hub

Aja como controle de finança familiar e crie um dashboard, que seja de fácil visualização e que seja editável, para colocar os gastos no decorrer dos mês, Temos os seguintes campos de gastos:
Habitação
Mãe
Tim
Plano de saúde
Pão
Academia
Mercado com subitens

Açougue

Verduras

Comida
Condomínio
Rosca
Shopp
Farmácia
João
Café

Campos de 'guardar dinheiro'
Poupança
Investimento

E que também tem a opção de adicionar novos campos, se necessário.

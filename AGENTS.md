- Finance category cards use a two-row mobile layout so labels, values, statuses, and actions remain visible at narrow widths.
- The dashboard owns receivable state and passes it to the editing section so summary totals and mutations share a single source of truth.
- Recurrence eligibility uses the persisted start period and the shared recurring-period helper for creation, synchronization, and displayed pin state, so past months cannot inherit future recurrence.
- Monetary fields use the shared MoneyInput backed by the tested parser in src/lib/money-parse.ts and store unformatted decimal strings in form state, so a typed "." (thousands or numpad decimal) or "," never changes saved amounts.
